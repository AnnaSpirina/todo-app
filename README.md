# Мой планер

Приложение-планировщик задач (to-do list) на React с адаптивной вёрсткой под мобильные устройства.

[Демо на GitHub Pages](https://annaspirina.github.io/todo-app/)

## Возможности

- Добавление и удаление задач
- Отметка задач как выполненных
- Фильтрация: все / активные / выполненные
- Отметка всех задач одновременно как выполненные
- Очистка выполненных задач

## Стек

- React (функциональные компоненты и props, хук `useState`, подъём состояния, управляемый input, рендер списков через `map` с `key`, условный рендеринг)
- CSS (кастомные стили, CSS-переменные, media queries)

## Запуск проекта локально

```
npm install
npm start
```

Приложение откроется на [http://localhost:3000](http://localhost:3000).

## Сборка

```
npm run build
```

## Деплой на GitHub Pages

```
npm run deploy
```
